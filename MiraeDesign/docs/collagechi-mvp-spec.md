# 콜라쥬치 MVP 기능 명세

## 1. 한 줄 정의

`콜라쥬치`는 포토카드 콜라주 무드의 펫을 짧게 돌보고 꾸미며 포카 컷을 수집하는 2D 브라우저 육성 게임이다.

## 2. 제품 목표

- 하루에 여러 번 짧게 들어오고 싶은 리듬을 만든다.
- 생존 압박보다 귀여운 반응과 수집 만족을 중심에 둔다.
- 꾸미기와 육성을 분리하지 않고 하나의 루프로 묶는다.
- 첫 버전은 적은 자산으로도 완성감 있게 보이는 범위에 집중한다.

## 3. 타깃 플레이 감각

- 세션 길이: 1~3분
- 권장 접속 빈도: 하루 3~6회
- 감정 보상: `돌봄`, `꾸미기`, `찰칵 저장`, `수집 채우기`

## 4. 핵심 루프

1. 접속 후 펫 상태와 오늘의 무드보드를 확인한다.
2. `간식`, `놀기`, `씻기`, `꾸미기` 중 필요한 행동을 고른다.
3. 행동 결과로 스탯, 표정, 방 연출, 보상이 즉시 변한다.
4. 조건이 맞으면 `스파클`과 포카 저장용 컷을 얻는다.
5. 저장된 컷으로 앨범을 채우고 다음 접속을 기다린다.

## 5. 코어 시스템

### 5.1 펫 상태값

| 스탯 | 설명 | 감소 방식 | 위험 상태 |
| --- | --- | --- | --- |
| 배부름 | 식사 상태 | 시간 경과로 감소 | 낮으면 축 처짐 |
| 기분 | 정서 상태 | 방치 또는 반복 행동 시 감소 | 낮으면 반응 감소 |
| 청결 | 위생 상태 | 시간 경과와 일부 행동 후 감소 | 낮으면 방이 지저분해짐 |
| 스파클 | 메타 재화 | 액션 성공, 미션, 수집 보상으로 증가 | 없음 |

### 5.2 액션 4종

| 액션 | 기본 효과 | 보조 효과 | 대표 리액션 |
| --- | --- | --- | --- |
| 간식 주기 | 배부름 상승 | 기분 소폭 상승 | 볼 빵빵, 반짝 |
| 놀아주기 | 기분 상승 | 배부름 소폭 감소 | 통통 점프 |
| 씻겨주기 | 청결 상승 | 기분 소폭 변동 | 거품, 뽀송 |
| 꾸미기 | 무드 점수 상승 | 포카 컷 조건 갱신 | 의상 체인지 |

### 5.3 시간 경과

- 앱을 닫아도 마지막 접속 시간 기준으로 상태가 감소한다.
- 감소는 완만하게 유지한다.
- MVP에서는 펫이 죽지 않는다.
- 장시간 방치 시 `삐짐`, `지저분함`, `특수 리액션 봉인` 정도만 적용한다.

### 5.4 성장 단계

| 단계 | 조건 | 변화 |
| --- | --- | --- |
| 베이비 | 시작 상태 | 기본 표정 3종 |
| 루키 | 스파클 누적, 1일 이상 | 액세서리 슬롯 1개 추가 |
| 스타 | 수집 수 증가, 스파클 누적 | 리액션 확장 |
| 아이콘 | 희귀 컷 획득 수 | 특별 포카 프레임 해금 |

## 6. 무드보드 시스템

### 목적

- 단순 반복 육성에 매일 다른 스타일 목표를 준다.
- 꾸미기와 돌봄을 같은 보상 루프에 연결한다.

### MVP 무드보드 7종

1. Peach Soda
2. Silver Bubble
3. School Crush
4. Mint Candy
5. Sleepover Pop
6. Cherry Flash
7. Cloud Angel

### 동작 방식

- 하루마다 테마 1개가 열린다.
- 테마는 선호 색, 아이템 태그, 목표 스탯 조건을 가진다.
- 해당 조건을 맞추면 추가 스파클과 특별 컷 확률이 오른다.

## 7. 포카 앨범 시스템

### 저장 컷

- 특정 행동 조합이나 상태 조합이 맞으면 `Save Photocard` 버튼이 활성화된다.
- 저장 시 현재 펫 표정, 의상, 배경으로 컷이 생성된다.

### 앨범 구조

- 일반 컷
- 무드보드 컷
- 희귀 컷
- 미획득 실루엣

### 수집 동기

- 같은 펫이라도 표정, 배경, 액세서리 조합으로 다른 컷이 만들어진다.
- 컬렉션 달성률이 성장 단계와 코스메틱 해금에 연결된다.

## 8. MVP 콘텐츠 범위

### 포함

- 펫 1종
- 방 배경 6종
- 의상/액세서리 12종
- 성장 단계 4개
- 무드보드 7종
- 기본 리액션 8종
- 포카 프레임 4종

### 제외

- 펫 2종 이상
- 친구 방문 시스템
- 미니게임 2종 이상
- 소셜 공유
- 서버 저장
- 가챠
- 실시간 푸시

## 9. 보상 구조

### 단기 보상

- 즉시 표정 변화
- 버튼 피드백
- 스탯 회복
- 작은 스파클 획득

### 중기 보상

- 일일 미션 달성
- 무드보드 완성
- 새 의상 해금

### 장기 보상

- 성장 단계 상승
- 희귀 포카 컷 수집
- 앨범 달성률 증가

## 10. 실패 상태와 톤

- 실패는 스트레스보다 귀여운 삐짐에 가깝게 처리한다.
- 예:
  - 배부름 낮음: 바닥에 엎드림
  - 청결 낮음: 먼지 구름, 찡그린 표정
  - 기분 낮음: 말풍선에 `...`
- 절대 피할 것:
  - 영구 사망
  - 과도한 벌칙
  - 장시간 미접속 유저 이탈을 부르는 강한 손해

## 11. 기술 범위

### 권장 스택

- 런타임: Phaser 3
- UI: React 또는 Next.js DOM 컴포넌트
- 언어: TypeScript
- 저장: `localStorage`

### 시스템 경계

- 시뮬레이션 상태는 캔버스 밖에서 관리
- 펫 애니메이션과 FX는 Phaser에서 처리
- HUD, 버튼, 서랍, 설정은 DOM으로 처리

## 13. MVP 제작 우선순위

1. 홈 화면 기본 루프
2. 시간 경과에 따른 상태 감소
3. 액션 4종과 리액션 연결
4. 꾸미기와 아이템 해금
5. 포카 저장과 앨범 열람
6. 무드보드 보너스

## 14. 첫 구현 스프린트 단위

### 스프린트 1

- 상태값 모델
- 홈 HUD
- 액션 버튼 4종
- 기본 펫 idle/react 애니메이션

### 스프린트 2

- 꾸미기 패널
- 아이템 데이터 구조
- 방 배경 교체
- 성장 단계 연동

### 스프린트 3

- 포카 저장 연출
- 앨범 UI
- 무드보드 시스템
- 저장/불러오기

## 15. 성공 기준

- 첫 접속 후 30초 안에 유저가 액션 1회와 저장 컷 1회를 경험할 수 있다.
- 하루 주기 보상 구조가 명확하다.
- 적은 자산 수로도 화면이 충분히 예쁘고 살아 있어 보인다.
- 펫을 돌보는 행위와 꾸미는 행위가 따로 놀지 않는다.
