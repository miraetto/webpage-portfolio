# 콜라쥬치 홈 화면 와이어프레임

## 1. 화면 목표

- 플레이어가 접속 3초 안에 펫 상태를 읽고 바로 행동할 수 있어야 한다.
- 중앙 플레이 영역은 펫과 방 연출을 보여주는 무대로 유지한다.
- UI는 포토카드, 스티커, 잡지 콜라주 감성을 주되 실제 플레이를 가리지 않는다.
- 정보는 한 번에 다 열지 않고, 기본 HUD + 서랍형 패널 구조로 나눈다.

## 4. 화면 영역 정의

### 상단 바

- 좌측: 게임 로고 또는 펫 이름
- 중앙: 현재 일차, 오늘의 무드보드 테마
- 우측: 인박스, 설정, 사운드 토글
- 역할: 메타 정보와 진입점만 배치하고, 장식은 최소화한다.

### 상태 칩

- 항목: `배부름`, `기분`, `청결`, `스파클`
- 형태: 둥근 칩 또는 작은 포카 라벨
- 상태 변화는 숫자보다 색과 표정 아이콘으로 먼저 읽히게 한다.

### 펫 스테이지

- 홈 화면의 중심이다.
- 펫, 배경, 장식, 이펙트가 모두 이 영역에서 보인다.
- 기본 상태는 `idle`이며 액션 직후 1~2초짜리 리액션 연출이 재생된다.
- 중요한 점: 긴 텍스트나 큰 패널을 이 영역 위에 오래 띄우지 않는다.

### 프롬프트 칩

- 현재 가장 필요한 케어를 1줄로 안내한다.
- 예: `배가 고파 보여요`, `방금 씻기면 스파클 +2`
- 튜토리얼이 끝난 뒤에도 남는 가벼운 가이드 역할을 한다.

### 일일 미션 칩

- 당일 무드보드와 연결된 목표 1개만 노출한다.
- 예: `실버 액세서리 2개 적용`, `기분 80 이상 유지`
- 메인 스테이지 아래 우측에 작게 둔다.

### 하단 액션 바

- 버튼 4개 고정: `Feed`, `Play`, `Wash`, `Style`
- 홈 화면에서 가장 자주 쓰는 버튼이므로 크고 명확해야 한다.
- 버튼 누름 시 즉시 반응이 오고, 길게 설명하지 않는다.

### 좌측 앨범 서랍

- 기본은 접힌 상태
- 열면 포카 컬렉션, 최근 저장 컷, 미획득 실루엣을 본다.
- 수집 욕구를 자극하지만 홈 플레이를 막지 않도록 너비를 제한한다.

## 5. 시각 디자인 가이드

### 무드 키워드

- `kitsch`
- `photocard binder`
- `scrapbook collage`
- `airbrush heart`
- `chrome sticker`
- `bubble type`

### 재질 레이어

- 종이 찢김 텍스처
- 글리터 스티커
- 반투명 PVC 포카 슬리브
- 크롬 하트와 별 아이콘
- 형광펜 낙서 포인트

### 추천 팔레트

- `Peach Soda`: `#ffb3c7`, `#ffd86b`, `#fff6f8`
- `Mint Pop`: `#b8ffd8`, `#7ce7d0`, `#f4fffb`
- `Sky Flash`: `#89d4ff`, `#dff5ff`, `#ffffff`
- `Silver Accent`: `#d9d9df`, `#aeb4c2`
- 텍스트 기본색은 검정 대신 `#2d2732` 같은 부드러운 차콜을 권장

### 타이포 방향

- 제목: 둥글고 존재감 있는 디스플레이 계열
- 본문: 작은 화면에서도 읽기 쉬운 산세리프
- 숫자 스탯은 스티커 라벨처럼 굵고 짧게

## 6. 모션 원칙

- 항상 흔들리는 UI는 피한다.
- 보상, 해금, 표정 변화, 포카 저장 순간에만 강한 모션을 준다.
- 추천 모션:
  - 액션 버튼 탭 시 120~180ms 팝
  - 포카 저장 시 셔터 플래시 + 슬리브 삽입 모션
  - 희귀 컷 획득 시 하트 컨페티

## 7. UI 우선순위

1. 펫 상태를 읽는다.
2. 액션 버튼을 누른다.
3. 결과 리액션을 본다.
4. 필요할 때만 앨범이나 꾸미기 패널을 연다.

## 8. 구현 메모

- 플레이 영역은 Phaser 캔버스 담당
- 상태 칩, 버튼, 서랍형 패널은 DOM UI 담당
- 홈 화면 기준 persistent UI는 데스크톱에서 전체 화면의 25% 이내로 유지
- 모바일에서는 앨범과 꾸미기를 바텀시트 또는 드로어로 접는다
